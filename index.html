🖥️ Chrome OS (apilio)

网页模拟桌面系统 (Web OS) - Tampermonkey 用户脚本

最新版本: 4.7 Insider

📖 项目介绍

一个功能强大的浏览器端虚拟桌面系统脚本。安装后，在任何网页右下角会出现"进入桌面模式"按钮， 点击即可进入一个完整的模拟桌面环境，支持文件管理、代码编辑、AI对话、Office文档处理等功能。

🗂️ 文件管理

支持 txt, cpp, md, docx, xlsx 等格式，可新建、删除、重命名、拖拽上传

💻 代码编辑

VS Code 风格编辑器，支持 C++ 编译运行、代码片段、括号补全

🤖 AI 对话

内置 AI 终端，支持 Markdown 渲染、上下文记忆、多模型切换

🎨 个性化

7 种色调主题、浅色/深色模式、窗口记忆、锁屏密码保护

📦 Office 支持

原生 Word/Excel 格式导出，非纯文本，真实格式文件

⚡ 快捷键

全功能快捷键支持，Ctrl+S 保存、Ctrl+Enter 换行、窗口管理等

🚀 安装步骤

安装 Tampermonkey 扩展

在 Chrome / Edge / Firefox 中安装 Tampermonkey（油猴）扩展

新建脚本

点击 Tampermonkey 图标 → "管理面板" → 左上角"+"号新建脚本

粘贴脚本内容

点击上方对应版本的"复制链接"按钮，在浏览器地址栏打开，全选复制脚本代码，粘贴到新建脚本中

修改 API（可选）

如需使用 AI 功能，将脚本中的 api.apilio.ai 替换为你自己的 API 地址

保存并运行

按 Ctrl+S 保存脚本，刷新任意网页，右下角出现"进入桌面模式"即表示安装成功
