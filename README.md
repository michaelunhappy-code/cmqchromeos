# 网页版 Chrome OS 用户Tampermonkey 脚本介绍
## [1]基础介绍
### 1、右下角的按钮可以进入桌面模式
### 2、进入之后，点击“退出桌面”即可退出
### 3、文件资源管理器可以管理文件，做得像windows，请善用快捷键及拖拽
### 4、右键上传文件
### 5、首次进入强制10s阅读条款，可以下载
## [2]设置介绍
### 1、模糊度设置及亮度设置
### 2、API Key (目前明文存储，以后会升级)
### 3、模型添加/删除
### 4、条款及使用须知
### 5、一键打包下载文件
### 6、改密码+存储安全密钥
### 7、存储统计（5.2及以下版本使用的是localStorage，反之使用indeedxdb）
## [3]搜索栏介绍
### 1、输入ai/对话 -> 进入ai对话框
### 2、输入娱乐/game/games -> 进入游戏窗口，旧版本升级游戏需要重置数据！
### 3、输入terminal，打开终端
### 4、输入文件名，可以搜索文件（大小写不区分）
